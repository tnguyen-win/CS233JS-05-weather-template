# Open Weather App

-   Originally for CS233JS-05-weather-template school project.
    -   Revised and improved upon for OCDLA CO-OP internship.

### Installation Prerequisites

1.  Install [Node.js](https://nodejs.org).

2.  Run NPM install to install Node dependencies.

```cmd
cd CS233JS-05-weather-template
npm install
```

3.  Include an OpenWeatherMap API key.

    1.  Make a file copy of `.env.example`.
    2.  Rename the copied file to `.env` or `.env.local`.
    3.  Include a valid OpenWeatherMap API key.

4.  Run the weather application.

```cmd
cd CS233JS-05-weather-template
npm run start
```

-   Alternatively `CMD_development.bat` to start the application.

    1. Run `CMD_development.bat`.
    2. Enter the number `1`.
    3. Click enter to run the inserted number.

5. (Optional) Setup and install VSCode extensions.
    1. Extension - [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode).
    2. Extension - [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint).
